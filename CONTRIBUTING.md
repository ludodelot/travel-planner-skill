# Contributing

1. Keep the repository free of personal data: names, addresses, employers, phone numbers, emails, booking references.
2. New facts need a date and a source in the text ("observed on the operator site, October 2026"). Prices and rules change.
3. Scripts use the standard library only and come with unit tests. Run `python3 -I -m unittest discover -s tests -v` before committing.
4. Reference files are one topic per file, short and concrete. Prefer a lesson learned with numbers over general advice.
5. Case studies must be anonymized.
