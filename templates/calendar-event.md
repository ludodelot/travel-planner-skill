# Calendar event template

Title: `<emoji> <place or action> · <qualifier>`

Description:

```
GO NOW (from my location): <directions link, no origin>

LOCAL TIME: <time zone>. Sunrise/sunset: <times if relevant>.
TYPE: PLAN | BOOKED | OPTIONAL | CONDITIONAL | UNVERIFIED

PHOTO: <viewpoint, focal range, composition>
VIDEO: <shot ideas>
LOGISTICS: <distance and minutes from previous stop>. <Cost>. <Rules>. <Warnings>.

MAP: <maps search link>
ROUTE FROM PREVIOUS STOP: <directions link with origin>
Approximate times: adapt to reality.
```

Fields:

- Location: the place name that resolves in Maps.
- Reminders: popup, 5 to 15 minutes (hours for flights and registrations).
- Availability: busy for fixed items, free for optional ones.
- Notifications: off.
- Color: one color per type (transport, stay, core stop, free culture, night, task).

Series: weekly rule with an end date and exception dates for holidays.
